# BC station data

Deliberately empty in this public repo — not an oversight. Real BC
station data (4 stations, `engine::parse_station()` format) exists and
is bundled for personal use, but lives in the private
`tidal_chart-station-data` companion repo instead: it's derived from
CHS data that isn't flatly public domain and is for personal use only,
and this repo's permissive MIT/Apache license would make anything
committed here freely redistributable (commercial use included), which
would contradict that. See `docs/DATA.md` and `docs/VALIDATION.md` for
the full reasoning, and `docs/ROADMAP.md` (0.2.0) for what's actually
been built and validated despite this directory being empty.
